# Feature image sources

Source files for card images that were designed rather than photographed. This folder sits outside
`content/`, `static/` and `assets/`, so Hugo ignores it and it is never published.

| Source | Output |
|---|---|
| `agentic-payments-lab.html` | `content/projects/agentic-payments-lab/feature.png` |

The Regulatory Horizon Scanner's `feature.png` is a crop of a real alert email generated by the
scanner itself, so it has no source file here.

## Updating the Agentic Payments Lab image

When a new part is published, edit the progress strip at the bottom of `agentic-payments-lab.html`:
add `done` to the next box, e.g. `<span class="p done">3</span>`.

## Rendering

Card images are 1200 × 821 px (the same shape as the other project cards). Render at 2× for sharp text,
then scale down. From the repo root, in Git Bash:

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=1200,821 \
  --screenshot="$(pwd -W)/design/feature-images/render-2x.png" \
  "file:///$(pwd -W)/design/feature-images/agentic-payments-lab.html"

python -c "from PIL import Image; Image.open('design/feature-images/render-2x.png').convert('RGB').resize((1200, 821), Image.LANCZOS).save('content/projects/agentic-payments-lab/feature.png', optimize=True)"

rm design/feature-images/render-2x.png
```

Without Pillow, drop `--force-device-scale-factor=2`, save the screenshot straight to
`content/projects/agentic-payments-lab/feature.png` and skip the resize step. The text will be a little softer.
